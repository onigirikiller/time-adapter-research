# Contributing

Bug fixes, reproducibility improvements, focused experiments, and clearer documentation are welcome.

For result-changing contributions, include:

- the exact script and commit;
- model and dependency revisions;
- dataset builder, seed, and split definition;
- hardware and runtime settings;
- both positive and negative-control metrics;
- a clear statement when results use synthetic or templated data.

Do not commit datasets, recordings, model weights, generated session logs, credentials, or third-party assets without a documented provenance and redistribution review. Keep the WebUI bound to localhost during development unless you have added an appropriate authentication and network boundary.

Please keep pull requests focused. A smaller reproducible change is easier to review than a bundle of unrelated experiment snapshots.
